# Contributing to Community Coalition

Thanks for helping explore more effective local event coordination. This repository is a collaborative planning space, not an official organization or an approval workflow for another group's facilities, funds, or name.

## Before adding information

- Keep **facts**, **inferences**, **proposals**, and **open questions** clearly distinct.
- Prefer original documents and upstream repositories with direct URLs and date of verification.
- Do not publish private organization materials, resident lists, student/child data, bank information, payment keys, private contact details, or unapproved logos.
- Do not assert that a school, PTO, HOA, or MUD has agreed to participate without its explicit authorization.
- Mark upstream software facts time-sensitive and recheck versions and licenses before implementation.

## Suggested workflow

1. Open an issue stating the problem, expected result, and sources to check.
2. For significant changes, work on a branch and submit a pull request.
3. Update the relevant document and [decision log](docs/decisions.md) if a decision has actually been authorized.
4. Review for privacy, authority, licensing, and consistency with the [scope](docs/vision-and-scope.md).

## Suggested issue format

- **Goal / stakeholder**
- **Known facts and sources**
- **Unknowns**
- **Proposed change / research**
- **Risk, privacy, legal authority**
- **Acceptance criteria**

Code is not yet present. Before adding third-party code, review its license and maintainers' attribution obligations, and agree on an appropriate license for original project code.
